# PDUFA Calendar (free, sourced from SEC filings)
Upcoming FDA PDUFA target action dates for US-listed biotech and pharma companies. Each date is pulled from the company's own SEC 8-K filing and comes with the exact sentence and a link. It updates daily through GitHub Actions.

- Live calendar: https://nidhi-bhai.github.io/pdufa-calendar/
- JSON: `data/upcoming.json` · RSS: `feed.xml`
- API, ticker filters, webhooks and MCP: https://apify.com/prospect_antechamber/pdufa-fda-catalyst-calendar

Not investment advice.
